# HTTP3 Kubernetes Masters Thesis

Masters thesis 2026 - HTTP/3 Implementation and Performance Analysis in Kubernetes Environments

## Overview

This repository contains the code, configuration, and documentation for a Masters thesis project focused on HTTP/3 protocol implementation and performance evaluation within Kubernetes orchestrated environments.

## Cross-Platform Development

This project is configured to work seamlessly across multiple devices and platforms:
- ✅ Windows (native, PowerShell, or WSL2)
- ✅ Linux
- ✅ macOS

### Quick Start

```bash
# Clone the repository
git clone https://github.com/david3453/HTTP3KubernetesMasters.git
cd HTTP3KubernetesMasters

# Start working on the project
git pull origin main
```
